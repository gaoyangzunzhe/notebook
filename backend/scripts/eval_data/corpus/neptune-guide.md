# Neptune 快速入门指南

本指南介绍如何在一个小时内完成 Neptune 的接入。

## 第一步：创建存储桶

登录控制台，进入「存储桶」页面，点击「创建存储桶」。桶名要求全小写、长度 3 到 63 位、只能包含数字和字母。创建时需要选择存储桶所在的区域，默认区域为华东 1。

## 第二步：生成访问 token

在「密钥管理」页面点击「创建 token」。token 只会完整显示一次，请立即保存到安全位置。token 的有效期可选 1 天、7 天或 30 天。

## 第三步：上传第一个文件

使用下面命令上传本地文件到指定桶：

curl -X POST https://api.neptune.example.com/v1/objects \
  -H "Authorization: Bearer <token>" \
  -F "file=@photo.jpg" \
  -F "bucket=my-bucket"

上传完成后，返回的 object_id 可以用于后续的下载、删除与分享。

## 第四步：配置桶权限

在桶设置的「权限」页面，可以为桶选择三种访问级别：公开读、私有、自定义策略。公开读意味着任何人无需认证即可下载桶内对象；私有则需要携带有效的 token。

自定义策略使用 JSON 描述，支持按 IP、前缀和对象名条件授权。策略变更立即生效，无需重启服务。

## 第五步：查看访问日志

在「日志」页面可以查询桶的访问日志，支持按时间范围和请求结果过滤。日志最多保留 90 天，超出后自动清除。

## 常见问题

问：上传超过 5GB 的大文件怎么办？

答：请使用分片上传接口。Neptune 的分片大小固定为 8MB，最多支持 10000 个分片。

问：如何为存储桶开启版本管理？

答：在桶设置中找到「版本管理」，点击开启即可。开启后不影响已存在的对象。

问：对象在哪个 URL 上访问？

答：私有对象通过 https://api.neptune.example.com/v1/objects/{object_id} 访问；公开对象可通过 https://{bucket}.neptune.example.com 直接访问。
